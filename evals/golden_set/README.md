# Golden Set

Σετ ερωτήσεων για τη μέτρηση της ακρίβειας ανάκτησης και του ποσοστού
hallucination του EvalAssist. Η μορφή τεκμηριώνεται στο `schema.md`.

## Γιατί δεν υπάρχουν εδώ οι πραγματικές ερωτήσεις

Οι ερωτήσεις αναφέρονται σε πραγματικές εκθέσεις αξιολόγησης προσωπικού και
περιέχουν αναγνωριστικά, ημερομηνίες και βαθμολογίες. Ζουν στο
`private/golden_set/questions.jsonl`, εκτός εκδοχής ελέγχου. Εδώ υπάρχει μόνο
συνθετικό δείγμα με ψευδή αναγνωριστικά (`questions.example.jsonl`), ώστε να
είναι σαφής η μορφή χωρίς έκθεση δεδομένων.

## Χρήση

Έλεγχος αρχείου πριν από κάθε εκτέλεση:

    python evals/golden_set/validate.py private/golden_set/questions.jsonl

Ο έλεγχος πιάνει άκυρο JSON, διπλά `id`, ασύντακτα `forbidden_patterns`,
ερωτήσεις Tier C χωρίς αιτιολόγηση, και μεικτούς λατινικούς/ελληνικούς
χαρακτήρες μέσα στην ίδια λέξη. Το τελευταίο είναι η ίδια κατηγορία σφάλματος
που αντιμετωπίζεται κατά την εισαγωγή από το `homoglyphs.py`: οπτικά ταυτόσημοι
χαρακτήρες παράγουν ερώτηση που δεν ταιριάζει ποτέ με το ευρετήριο, οπότε η
αποτυχία μοιάζει με αποτυχία ανάκτησης ενώ είναι σφάλμα πληκτρολόγησης.

Έξοδος `0` αν όλα περνούν, `1` σε εύρημα, `2` σε λάθος κλήση.

## Πού τρέχει τι

Το Tier A είναι ντετερμινιστικό και δίνει ταυτόσημο αποτέλεσμα σε κάθε μηχάνημα.

Τα Tier B και C περνούν από τη γεννήτρια, άρα εξαρτώνται από το μοντέλο. Baseline
καταγράφεται ΜΟΝΟ από μηχάνημα με το μοντέλο παραγωγής. Μέτρηση από μικρότερο
μοντέλο δεν είναι συγκρίσιμη και δεν καταχωρείται.

Κάθε εκτέλεση καταγράφει commit hash, όνομα μοντέλου και `prompt_version`.
Χωρίς αυτά τα τρία, δύο μετρήσεις δεν συγκρίνονται μεταξύ τους.
