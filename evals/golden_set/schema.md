# Golden Set: δομή και κανόνες

Σετ ερωτήσεων για μέτρηση ακρίβειας ανάκτησης και ποσοστού hallucination.
Οι πραγματικές ερωτήσεις περιέχουν δεδομένα προσωπικού και ΔΕΝ είναι tracked:
ζουν στο `private/golden_set/questions.jsonl` (καλύπτεται από `.gitignore`).
Εδώ τεκμηριώνεται μόνο η μορφή, μαζί με συνθετικό δείγμα.

## Μορφή

JSONL, μία ερώτηση ανά γραμμή, UTF-8 χωρίς BOM.
Line-oriented ώστε τα diffs να είναι αναγνώσιμα και να μην απαιτείται yaml dependency.

Κοινά πεδία:

| πεδίο | τύπος | περιγραφή |
|---|---|---|
| `id` | string | `A-01`, `B-07`, `C-03`. Σταθερό, δεν ανακυκλώνεται ποτέ. |
| `tier` | `A`\|`B`\|`C` | βλ. παρακάτω |
| `mode` | `structured`\|`semantic` | ποιο μονοπάτι ανάκτησης δοκιμάζεται |
| `question` | string | ακριβώς όπως θα γραφόταν στο UI |
| `person_id` | string | scope απομόνωσης |
| `period` | string\|null | `null` = όλο το εύρος |
| `expected` | object | εξαρτάται από `kind` |
| `notes` | string | αιτιολόγηση, υποχρεωτική στο Tier C |

## Tiers

**A: ντετερμινιστικές.** Structured lookup από SQLite, μηδέν LLM.
Κάθε αποτυχία είναι bug στο SQL ή στην εξαγωγή, ποτέ στη γεννήτρια.
Τρέχει και στα δύο μηχανήματα με ταυτόσημο αποτέλεσμα.

**B: semantic με απάντηση στο έγγραφο.** Μετρά αν το σωστό chunk φτάνει
στη γεννήτρια και αν η απάντηση παραπέμπει στη σωστή σελίδα.

**C: semantic ΕΚΤΟΣ εγγράφου.** Μετρά ποσοστό hallucination.
Η σωστή απάντηση είναι άρνηση. Κριτήριο ποιότητας ερώτησης: πρέπει να έχει
λεξιλογική επικάλυψη με το έγγραφο, ώστε ο reranker να επιστρέψει chunk με
υψηλό score που όμως δεν περιέχει την απάντηση. Προφανώς άσχετη ερώτηση δεν
δοκιμάζει τίποτα.

Τα Tier B/C τρέχουν ΜΟΝΟ στη μηχανή με το μοντέλο παραγωγής (Krikri).
Αριθμός από μικρότερο μοντέλο δεν είναι συγκρίσιμος και δεν καταγράφεται ως baseline.

## `expected` ανά kind

```json
{"kind":"exact","value":3}
{"kind":"set","values":["...","..."]}
{"kind":"contains","must_include":["..."],"must_not_include":["..."],"must_cite":{"doc_id":"...","page":2}}
{"kind":"refusal","forbidden_patterns":["\\d+\\s*(ημέρ|μήν)"],"human_label_required":true}
```

`set` = σύγκριση χωρίς σειρά.
`must_cite` = υποχρεωτική παραπομπή· λείπουσα παραπομπή είναι αποτυχία ακόμα και
με σωστό περιεχόμενο.
`human_label_required` = ο αυτόματος ανιχνευτής άρνησης είναι regex πάνω σε
διατυπώσεις και δεν είναι αξιόπιστος. Φάση 1: καταγραφή και χειροκίνητος
χαρακτηρισμός. Φάση 2: αυτοματοποίηση αφού συγκεντρωθούν πραγματικές απαντήσεις.
Ίδια λογική με τον rank validator.

## Εκτελέσεις

Αποτελέσματα στο `private/golden_set/runs/<tier>_<YYYYMMDD>.jsonl`, ποτέ tracked.
Κάθε run καταγράφει `prompt_version`, όνομα μοντέλου και commit hash, αλλιώς οι
αριθμοί δεν συγκρίνονται μεταξύ τους.
